## 🚀 Engineering Highlights

### ☸️ Kubernetes & Infrastructure Automation

- Provision and manage highly available Kubernetes infrastructure using Terraform and Infrastructure as Code practices.
- Support production workloads through cluster operations, deployment troubleshooting, scaling, and infrastructure lifecycle management.
- Coordinate application deployments across government and enterprise platforms.
- Use GitOps workflows to improve deployment consistency and operational traceability.

### 🗄️ Object Storage & Security

- Design and operate **distributed, S3-compatible MinIO storage architectures** using multi-node, multi-drive deployments for production workloads.
- Integrate **OAuth 2.0 / OpenID Connect (OIDC)** with Keycloak to support centralized identity and access management.
- Apply storage security practices covering authentication, authorization, access policies, secure service integration, and controlled object access.
- Work with S3-compatible APIs, presigned URLs, and Security Token Service (STS) workflows for application-to-storage integration.

### 🔄 CI/CD & Secure Software Delivery

- Build and maintain automated CI/CD pipelines for application delivery.
- Integrate **SonarQube quality gates, security analysis, and Software Bill of Materials (SBOM) generation** into CI/CD pipelines to improve code quality, vulnerability visibility, and software supply chain security.
- Streamline deployment processes, reducing manual deployment effort by approximately **30%**.
- Apply security and operational considerations throughout the software delivery lifecycle.

### 📈 Observability & Production Reliability

- Work across metrics, logs, traces, and application monitoring using Prometheus, Grafana, Elastic Stack, and OpenTelemetry.
- Investigate production incidents, perform root-cause analysis, and coordinate remediation across application and infrastructure layers.
- Correlate Cloudflare edge logs with Wazuh SIEM alerts to detect and mitigate a live multi-IP Layer 7 DDoS attack.
- Diagnose authentication and SSO failures involving OAuth 2.0, reverse proxies, and identity services.

### 🗄️ Identity, Storage & Platform Services

- Design and operate OAuth 2.0-integrated, S3-compatible MinIO distributed storage architectures using multi-node and multi-drive deployments.
- Integrate Keycloak-based identity and access management with applications and platform services.
- Work with object storage, reverse proxies, TLS, access policies, and service integrations in production environments.

### 🤖 AI-Powered Infrastructure Operations

- Experiment with self-hosted LLM inference and agent-based automation for internal engineering workflows.
- Develop an AI-assisted Kubernetes operations concept using Kafka, Qdrant, n8n, and LLMs to support natural-language infrastructure queries.
- Explore a two-track anomaly detection pipeline using OpenSearch Random Cut Forest and custom PyOD/Isolation Forest models for traffic and authentication anomalies.
