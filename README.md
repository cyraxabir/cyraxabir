## 🚀 Engineering & Security Highlights

### 🛡️ Security Operations, Threat Defense & VAPT
- Architect and operate SOC monitoring and automated response pipelines integrating **Wazuh, Shuffle, IRIS, and MISP**.
- Correlated Cloudflare edge logs with Wazuh SIEM alerts to detect and mitigate a **live multi-IP Layer 7 DDoS attack**.
- Conduct manual and automated **VAPT** across web apps, APIs, and infrastructure using Burp Suite, Nessus, Acunetix, Nmap, and Trivy, prioritizing remediation by CVSS.
- Support **ISO/IEC 27001, NIST, and OWASP** governance through control assessments, audit evidence collection, and patch coordination.

### ☸️ Kubernetes, IaC & Production Reliability
- Provision and manage highly available Kubernetes clusters with Terraform, Ansible, and GitOps workflows across **10+ government and enterprise platforms**.
- Build end-to-end observability across metrics, logs, and traces using **Prometheus, Grafana, OpenTelemetry, and Elastic Stack** to accelerate root-cause analysis.

### 🔄 Secure CI/CD & Supply Chain Security
- Build automated delivery pipelines integrating **SonarQube quality gates, Trivy scanning, and CycloneDX SBOM / Dependency-Track** analysis.
- Streamlined release workflows to reduce manual deployment effort by approximately **30%**.

### 🗄️ Identity & Distributed Storage Security
- Design and operate **multi-node, multi-drive MinIO (S3-compatible)** storage architectures integrated with **Keycloak (OAuth 2.0 / OIDC)** and Security Token Service (STS) workflows.
- Harden reverse proxies (Nginx, HAProxy), TLS configurations, RBAC policies, and SSO integrations in production.

### 🤖 AI-Assisted Security & Infrastructure Operations
- Build LLM and agent-driven automation using **Kafka, Qdrant, n8n, and self-hosted models** for natural-language Kubernetes troubleshooting and automated log triage.
- Explore two-track anomaly detection pipelines with OpenSearch Random Cut Forest and PyOD/Isolation Forest models for traffic and authentication anomalies.
